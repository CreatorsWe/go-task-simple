### `var value from flags`

从 task <task_name> --var="src_path='./src';time=3" 命令行获取 vars 变量的值，目地是对变量的动态替换。
由于任意值会在命令中被替换成字符串，所以从命令行变量值都是 string。


### `immediate print`

利用 Pipe 实现 output 消息即时打印,而不是命令执行完后统一打印所有信息。并行模式下，不再保证打印的顺序。

### `less prompt`

success prompt --> 不显示了

error prompt -> 仅在 stderr error 开头显示 [task:step 1] <err_msg>. exitcode status:

timeout prompt -> [task] timeout in <time> second(s).

continue prompt --> 不显示了
